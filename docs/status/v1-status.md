## Decisions from document comparison

- Compose includes MinIO and a separate ingestion scheduler because design section 31.1 is more specific than the abbreviated V1.0 gate service list.
- V1.2 uses the plan's ≥90% core-field target for the initial seed batch. The design's ≥95% target belongs to the V2 Full-market Coverage Gate; these measure different release scopes.
- .NET 8.0.422 is used for local reproducibility and remains LTS on the implementation date. A runtime-major upgrade requires an ADR plus full regression/golden tests.
- The V1.2 reviewed seed starts at the plan's lower bound of 10 brands. Ford remains registry-only because the official product host returns HTTP 403 to both HTTP and browser automation; Škoda remains registry-only because its supplied official model URL currently redirects to a 404 page. Volkswagen/Škoda are explicitly conditional on resources in the plan, so neither inaccessible evidence nor fabricated facts were published.
- Public product prices keep the source's stated effective date when the official announcement provides one; otherwise a live product page is observed-dated in `Asia/Ho_Chi_Minh`. This preserves honest temporal provenance instead of inventing an earlier validity period.
- The required query `tucson hybrid` ranks the current official Vietnam Tucson candidate first, but the result remains `Ice` with an unknown/unannounced public price. Hyundai Vietnam's current page does not evidence a Tucson Hybrid trim, so search recall is allowed to be partial while product facts are never relabeled.
- V1.3 exposes on-road/color/energy filter contracts but unknown values never match them. Exact on-road ranges are populated by the effective-dated regional engine in V1.5; no percentage-based placeholder is fabricated in V1.3.
- V1.4 renders only image URLs whose persisted `RightsStatus` is explicitly approved by the API. Because the reviewed V1 seed currently has no licensed/owned/official-press image records, the product deliberately shows “Chưa có ảnh được cấp quyền” instead of fetching unrelated web images.
- V1.5 treats the design formula as authoritative and uses the plan's dated legal fixtures only after verifying the competent-authority pages. Province Open API v2 supplies labels and numeric administrative identifiers; registration area is mapped from stable numeric codes (`01`, `79`) rather than mutable UI labels.
- New, eligible vehicles use the verified first-inspection exemption rule and therefore receive a sourced `0` inspection component. The separate VND 250,000 inspection-service tariff is not added to a transaction that is exempt from that inspection.
- V1.6 follows the design's condition-preserving PHEV split instead of using the plan's BYD 1.1 L/100km full-battery weighted example as a fuel-mode rate. The calculator uses the official 4.72 L/100km charge-sustaining value only for engine kilometres and 16.9 kWh/100km only for charge-depleting kilometres; the weighted figure remains documented but is never mixed into either leg.
- The Vietnam Register VF 6S type `N5DG03` disclosure is mapped explicitly and reviewably to the current catalog's VF 6 Eco naming. The source type, value and mapping note are returned to users rather than silently presenting the catalog label as if it appeared in the authority record.
- VinFast free charging is a versioned, effective-dated promotion rather than a tariff override. It applies only after the user confirms vehicle/owner eligibility, respects the monthly session cap, and never hides post-charge service fees; `normalizedCost` always retains the underlying V-Green tariff.
- V1.7 does not fabricate trim-specific maintenance or tyre schedules where no reviewed dataset exists. Those components are explicit, editable user estimates with a worst-reasonable band; compulsory insurance, road usage and inspection continue to come from the versioned legal-rule engine unless the user deliberately supplies a labelled override.
- Conservative/Balanced/Aggressive thresholds are product configuration rather than hidden domain constants or financial advice. Normalized operating ownership cost is the eligibility gate; current promotional cost and worst-reasonable cost remain visible as separate bands. Purchase price and loan payment stay outside V1.7 by design.
- V1.8 keeps acquisition funding, loan cash flow and operating ownership as separate results, then composes them only in `TotalMonthlyVehicleCommitment`. A fully `FamilyFunded` purchase is `ExternallyFunded/NotApplicable` for user cash and financing even when the independent ownership gate fails. Because the reviewed dataset currently contains no official bank/dealer rate snapshot or published dealer financing offer, the product labels entered rates `UserInput` and applies no invented bonus; the API can use an official `SourceFact` when one is later published.
- V1.9 share URLs contain trim IDs, region, calculation date and named public presets only. Sensitive salary, debt, cash and rate inputs stay inside the server-built preset request and never appear in browser URL state. The compare engine evaluates at most four trims with one shared scenario and preserves `UNKNOWN` as distinct from `NOT_AVAILABLE`.
- V1.10 exposes the design's full-market coverage criteria as an honest operational gate but does not claim they are met by the V1 validation seed. The current 11-brand scope therefore remains explicitly `BLOCKED` against the 15-brand initial target even though every published core fact is either sourced or explicit `UNKNOWN`.
- Admin writes refresh the PostgreSQL catalog materialized view and rotate a distributed cache generation only after persistence succeeds. Review decisions never infer publication from approval alone: an unedited approval remains an approved worker input, while edit-and-publish and manual override paths are separately audited.

## V1.8 gate evidence

## V1.10 gate evidence

The integration gate created, updated and removed only an isolated unsourced draft under an existing hierarchy, updated a reviewed source without changing its value and left immutable before/after audit evidence.
